# Шрифты PDF-отчётов

DejaVu Sans 2.37 (обычный и полужирный) обеспечивает кириллицу и одинаковый вид
отчётов в Windows и Linux без установки системных шрифтов.

Источник: https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37

Архив `dejavu-fonts-ttf-2.37.zip`, SHA-256:
`7576310b219e04159d35ff61dd4a4ec4cdba4f35c00e002a136f00e96a908b0a`.
Файлы скопированы без изменения; условия распространения находятся в `LICENSE`.
Шрифты включаются в окружение CI вместе со scripts; runtime-образ LAB 1 их не содержит.
